# RAB Rumahku - Mobile (Flutter)

Repo ini sudah dilengkapi GitHub Actions (`.github/workflows/build-apk.yml`)
yang otomatis membuild APK setiap kali ada push ke branch `main`, atau bisa
dijalankan manual lewat tab **Actions > Build APK > Run workflow**.

Hasil APK bisa diunduh dari halaman **Actions** run yang sukses, di bagian
**Artifacts** dengan nama `rab-rumahku-apk`.
